# Spec Delta

## ADDED Requirements

### Requirement: 压缩后指令完整存活

工作流 skill SHALL 保证其指令内容在上下文压缩后完整可用：压缩后继续执行所必需的红线内容（恢复协议、全局纪律、不得静默假设待决项的处置规则）SHALL 保留在 skill 入口正文内；其余指令内容 SHALL 位于可按需读取的同 bundle 资源文件中，且入口 SHALL 提供足以定位这些文件的路由指引；外移与路由 SHALL NOT 改变既有任何 Requirement 约束的行为语义。

#### Scenario: 压缩后红线内容仍可用

- **WHEN** 上下文压缩发生在工作流执行中（如落档完成后压缩上下文再继续）
- **THEN** 恢复协议与全局红线仍完整存在于 skill 入口正文，流程从工件与任务勾选态无损接续，不重复已完成任务

#### Scenario: 外移内容可按需读取

- **WHEN** 某阶段需要外移文件中的指令（如派发子代理时的模型路由、异常时的失败处置、阶段 1 的双线派发模板）
- **THEN** 入口的路由指引足以让会话定位并读取对应资源文件，获得与外移前等价的指令内容

#### Scenario: 外移不改变行为语义

- **WHEN** 指令内容被搬入资源文件或入口被改写为骨架
- **THEN** 既有 Requirement 约束的行为语义与触发条件保持不变，skill 的名称与描述逐字节一致，工作流入口与触发行为不变
