## 决策 5 对 smoke/ 结构的修正（supersede 探索草案 §三.1）

```
<所测项目根>/smoke/
├── cases.md                              # 全量用例库（入库）：分组 A–G + 稳定编号（A-01…）
│                                         # 7 列：编号|用例|类型(正/反)|前置|步骤|期望结果|证据要求
└── runs/                                 # 历次运行记录（目录/运行）
    └── <YYYY-MM-DD>-<full|任务号>/
        ├── record.md                     # 逐项结果回填（通过/失败/N/A/观察项 + 证据链接）+ 分组汇总
        ├── report.md                     # 结论性报告（原 §7.1 骨架，scope 入标题）
        └── *.png 等                      # 截图/大文件（gitignore，不入库）
```

与探索草案差异：runs/ 从「单文件 <日期>-<scope>.md」升级为「运行目录」——报告、逐项记录、截图同目录聚合；报告与运行记录仍两文件并存（受众不同：报告面向用户结论，record 面向追溯明细）。
