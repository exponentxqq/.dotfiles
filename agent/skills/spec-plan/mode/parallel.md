## 并行模式（`--parallel`，具名 fresh 子代理）

**派发**：**同一条消息**内并发两次 `subagent`——`subagent(name="plan-a", description="…", prompt="…")` 与 `subagent(name="plan-b", …)`，两线并行执行。调用**立即返回**，回执 `started subagent <name>`，完成通知自动递送——**没有后台派发参数**；**不用** `subagent_fork`（继承本会话上下文，破坏两线独立性，且不能按线选模型）。

**命名**：`plan-a` / `plan-b`；全名 **≤32 字符、小写 kebab、字母开头、非保留名 `lead`**。重名被拒 → 追加变更短码重试一次（`adapt-spec-skills-to-dsh-rc5` → `plan-a-adapt28`），再拒即上行 `异`，不循环；重派追 `-r<n>`（`plan-a-r2`）。

**模型路由**：两线分别按 `lineA`/`lineB` 键应用（显式 `--model` 覆盖优先；三档回退见 SKILL.md 第八节与 [../refs/routing.md](../refs/routing.md)）。**规划键恒适用**——具名子代理支持模型选择，无编排例外。

### 提示模板（单版；两条线除「方向」外逐字等形，字段缺一不可）

```
项目根（绝对路径）：<project root>
需求原文：<用户需求，逐字>
你的规划方向：<A：需求与价值、范围与边界——要解决什么、为谁解决、边界在哪 | B：实现与约束、反例与风险——怎么做、会怎么错、代价是什么>
你的产物路径：/tmp/spec-flow/<change>/line-a.md   （B 线为 line-b.md）
你是主会话以 `subagent` 派发的 **fresh** 子代理（上下文独立、提示自包含）；**最终文本即回执**。
产出要求：一份**完整的轻量规划草案**，下列 7 个字段**全部**写到、字段名照抄，不得缺项、不得合并、不得只写你方向内的那几项：
  1) 目标与非目标  2) 范围与边界  3) 方案与取舍  4) 任务拆分草案  5) 验证思路  6) 风险与未知项  7) 假设清单
另立「待决问题」节（在 7 字段之外）：每条含 问题 / 选项 / 你的推荐 / 影响面；无待决项时写「无」。
事实自己查（读代码、读 spec、跑只读命令）；查不到的写进「假设清单」与「风险与未知项」。
硬约束：
- 只允许写你自己的那一份产物文件；不得写项目文件、不得改 openspec/、不得 git add/commit。
- 不与用户直接交互：**你看不到用户、也不能提问**——被拥有的子代理调用提问工具会被以错误码 `DELEGATED_CALLER` 拒绝。需要用户拍板的决策**不要自行假设**：写进产物「待决问题」节（每条含：**问题、选项、你的推荐、影响面**），并在**最终回复**中把它们列为本轮 TOP 待决项后结束回合——**不要为等答复而空转、阻塞或轮询**；主会话会代问用户并按同一实例回送答复（见「待决问题的中转交互协议」）。
- 不得读取、引用另一条规划线的产物，也不得等待它。
- 每条线提示末注入上行精简段：`send_message(agent="lead")` 直报主会话（**仅决/异两类**：需拍板 / 无法继续），**不在此等待答复**、不重试不阻塞，失败即降级为回执上浮；占位取「A线|B线」，模板见 `spec-apply/refs/coordination.md §7`。
```

**派发补正**：两线均返名才算「已派发」；缺一 → **原提示补派一次**（同名重试，报重名按上节加短码）。两线独立性铁律与 7 字段契约见 SKILL.md 第四节，本文件不复制。

**线失败**：产物缺失 / 为空 / 答非所问 / 与另一线雷同 → 先 `send_message(agent="plan-a")` **回送同一实例补正一次**（保留上下文，不新派）；实例不可恢复（`AGENT_NAME_NOT_FOUND` 或补正后仍无产出）→ **冷兜底重派** `plan-a-r2`（新名，附上轮回执摘要）。仍失败 → 如实报告，由**用户决定**是否降级串行（**不得静默降级**）；其余异常见 [../refs/failure-modes.md](../refs/failure-modes.md)。

### 回执核对（主会话必做）

两份产物**都存在且非空** → 各读一遍，核对 7 字段齐备、能否明显看出两线**方向差异**（雷同或字段残缺 → 独立性不成立，按线失败处理）→ 输出 3–8 行阶段摘要（两线关键判断、可见分歧点、单边遗漏信号、**每线实际路由**）作为阶段边界汇报；两线待决项按 SKILL.md 第四节中转协议②**并入阶段 1.5 统一提问**（按第十节追问契约发起；不另开通道、不积压）。上行早到亦同：**收到上行仍并入 1.5**，提问节奏不变。
