# 交付自查清单（内置通用框架）

> 这是 skill 的默认检查清单，**可直接编辑扩充**：增删表格行、补充您的专属规范（客户命名规范、格式要求等）都会在下次审核时生效。
> 敏感信息检查不在此维护 —— 见 [SKILL.md](SKILL.md) 的「敏感信息硬规则」，其优先级最高且永远执行。

## 一、完整性

| 检查项              | 适用类型 | 默认级别    | 判定要点                                                          |
| ------------------- | -------- | ----------- | ----------------------------------------------------------------- |
| 清单承诺 ≠ 实物     | 全部     | **Blocker** | 对照交付清单 / `DELIVERY.md` / 方案书附件说明逐项核对，缺失即命中 |
| 占位符未替换        | 全部     | **Blocker** | `XX`、`XXX`、`待定`、`TODO`、`lorem ipsum`、`待补充`、模板痕迹    |
| 空文件 / 0 字节文件 | 全部     | Major       | 逐个检查文件大小，空文件通常意味着漏产出                          |
| 引用失效            | 文档     | Major       | 文中「见附件」「详见链接」指向的文件/链接在本包中不存在或不可达   |
| 章节/编号残缺       | 文档     | Major       | 目录与正文对应、章节编号连续、表格编号连续                        |

## 二、准确性

| 检查项       | 适用类型  | 默认级别 | 判定要点                                                                                                             |
| ------------ | --------- | -------- | -------------------------------------------------------------------------------------------------------------------- |
| 错别字       | 全部      | Major    | 常见：登陆→登录、帐号→账号、按装→安装、既使→即使、截止/截至误用、以经→已经、其它→其他（前后不统一）                  |
| 数字矛盾     | 文档/报表 | Major    | 金额、数量、百分比、预算在全文前后一致；合计 = 明细之和                                                              |
| 日期自洽     | 全部      | Major    | 格式统一；时间线不矛盾（如「已完成验收」与状态「待验收」并存）；不与当前时点冲突                                     |
| 版本号一致   | 全部      | Major    | 封面/页脚/文件名/文档修订记录中的版本一致                                                                            |
| 表格数据错位 | 报表      | Major    | 表头与列内容对应（如「手机」列填了姓名）；单位/币种明确                                                              |
| 版块语义一致 | 文档      | Major    | 对比性版块（优势/待关注、通过/风险、亮点/问题）中条目方向须与版块定位一致——负面版块出现正面/中性描述、或反之，即命中 |
| 版块内容重复 | 文档      | Major    | 同一列表内两条目完全重复或仅措辞微差（如「个人优势」02 与 05 相同）                                                  |
| 术语统一     | 全部      | Minor    | 同一概念全文一种叫法；中英混用（如 dashboard）统一                                                                   |

## 三、跨文件一致性

| 检查项                 | 适用类型 | 默认级别 | 判定要点                                                   |
| ---------------------- | -------- | -------- | ---------------------------------------------------------- |
| 人名 / 客户名 / 项目名 | 全部     | Major    | 同一实体在不同文件中写法一致（如「XX 公司」vs「XX 集团」） |
| 联系方式               | 全部     | Major    | 同一人的电话/邮箱在各文件中一致；同一号码不张冠李戴        |
| 关键事实               | 全部     | Major    | 交付范围、金额、工期、验收状态在不同材料间不矛盾           |
| 编号体系               | 文档     | Minor    | 文档编号、合同号、项目代号前后一致                         |

## 四、规范性

| 检查项                   | 适用类型 | 默认级别 | 判定要点                                                                                                                      |
| ------------------------ | -------- | -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 文件命名                 | 全部     | Minor    | 无「最终版2-改」「新建文件夹」「副本」类命名；无多余空格/特殊字符                                                             |
| 目录结构                 | 全部     | Minor    | 分类清晰、无冗余嵌套、与清单描述相符                                                                                          |
| 文档格式                 | 文档     | Minor    | 标题层级、字号、日期格式、标点风格统一                                                                                        |
| 元数据 / 批注 / 备注泄露 | 文档     | Minor    | 文档属性（作者、公司、模板路径）、批注、PPT 演讲者备注中的内部信息；内容涉及商业敏感（报价底线、内部策略）时上调为 Major 以上 |

## 五、交付卫生

| 检查项          | 适用类型    | 默认级别 | 判定要点                                                          |
| --------------- | ----------- | -------- | ----------------------------------------------------------------- |
| 系统垃圾文件    | 全部        | Major    | `.DS_Store`、`Thumbs.db`、`desktop.ini`、`._*`                    |
| 临时 / 备份文件 | 全部        | Major    | `*.bak`、`*.tmp`、`~$*`、`*副本*`、`*.orig`                       |
| 重复文件        | 全部        | Minor    | 内容相同文件（可对同尺寸文件做 md5 比对），或同一文件散落多目录   |
| 调试残留        | 代码包      | Major    | `print("debug:...")`、`console.log`、`debugger`、大段注释掉的代码 |
| TODO / FIXME    | 代码包/文档 | Minor    | 遗留未处理的标记（若内容涉及未完成章节则升为 Blocker）            |

## 六、图片 / 截图专项

| 检查项            | 适用类型 | 默认级别    | 判定要点                                         |
| ----------------- | -------- | ----------- | ------------------------------------------------ |
| 占位符 / 草稿痕迹 | 图片     | **Blocker** | 图中 `XXX 公司`、测试数据、水印「草稿」          |
| 图中敏感信息      | 图片     | 按硬规则    | 界面截图中的账号、手机号、内网地址、真实业务数据 |
| 内容与文案矛盾    | 图片     | Major       | 截图展示的状态/数据与文档描述冲突                |
| 成像质量          | 图片     | Major       | 模糊、拉伸变形、关键内容被裁切                   |
| 多图一致性        | 图片     | Minor       | 同批截图的风格、配色、字号统一                   |
